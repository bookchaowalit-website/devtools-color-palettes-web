# Swatch Library — Design direction

## Direction

Assigned operate-mode direction translated into a physical sample library: a
palette is a study, the presets are on a shelf, and export is a token drawer.

## Visual system

- Warm paper and graphite rules keep the colors themselves authoritative; muted
  green labels and vermilion selection marks identify state.
- Outfit is the studio voice; DM Mono handles HEX values and export tokens.
- Swatch strips, shelf rows, and a visible token drawer replace generic cards.

## Interaction contract

Selecting a preset, copying an individual HEX, copying the full palette, and
exporting CSS/Tailwind/JSON all work from the same selected palette. Names and
values remain visible so color is never the only signal.

## Responsive behavior

The shelf becomes a full-width list above the study and swatches keep their
vertical labels on narrow screens.
