# Color Palettes

Browse curated palettes and export tokens for CSS or Tailwind.

## Features
- Preset palettes
- Click-to-copy swatches
- Export CSS variables, Tailwind colors, JSON

## Limitations
- Presets are static demo data
- Image export not included

## Run
```bash
npm install
npm run dev
```

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Fully client-side (no API keys)

## Honesty notes
- Portfolio developer utility showcase
- Not a multi-tenant SaaS product
